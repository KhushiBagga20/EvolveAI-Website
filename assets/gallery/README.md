# Gallery photos

Event and community photos for the archive section go here.

- Prefer `.webp` or `.avif`, roughly 1600px on the long edge.
- Name them after the event, e.g. `finvasia-hackathon-2026.webp`.
- Reference them from the matching `.event__frame` in `index.html`
  (see the main README for the snippet). Always write a real `alt` text.
