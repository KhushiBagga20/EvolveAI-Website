# Partner logos

Industry collaborator logos for the marquee go here.

- Single-colour SVG works best (the marquee sits on the blue block, so a cream
  `#F5F1E8` fill reads well); transparent PNG also works.
- Swap a wordmark in `index.html`:
  `<li class="logo"><img src="assets/logos/microsoft.svg" alt=""></li>`
- Keep the sr-only sentence above the marquee in sync — it is what screen
  readers announce.
