# Partner logos

The "Beyond the classroom" list on the homepage sets partner names as type,
with a small shape from the shape language between each one. If logos are
preferred later, put them here:

- Single-colour SVG works best (fill `#13072E`, the page's ink colour);
  transparent PNG also works.
- Swap a name in `index.html` for an image with real alt text:
  `<li><img src="assets/logos/microsoft.svg" alt="Microsoft"></li>`
  and give the list's images a height in `css/sections/partners.css`
  (around `0.8em` keeps them in step with the names).
